# Chapter 5: Specialized Data Structures (`ds`)

The `ds` package provides generic in-memory data structures:
1. **`RingBuffer[T]`**: Fixed-capacity circular buffer with $O(1)$ push, overwriting on overflow, and zero-copy contiguous segmentation.
2. **`SyncRingBuffer[T]`**: Thread-safe circular buffer synchronized via `async.Sync`.
3. **`Table[V]`**: Multi-indexed relational in-memory store supporting unique primary keys, secondary unique indices, and non-unique group indices with atomic insert rollback.
4. **`Grid[R, C, V]`**: 2D sparse matrix/coordinate structure with dual secondary indices for fast row and column slicing.

```go
import "github.com/azuiktech/kleisli-go/ds"
```

---

## 1. RingBuffer[T] (Circular Buffer)

A fixed-capacity circular ring buffer that continuously stores the most recent items. When full, `Push` silently overwrites the oldest element.

### Type Definition & Construction

```go
type RingBuffer[T any] struct { /* unexported fields */ }
```

| Function / Method | Signature | Description |
|---|---|---|
| `Ring[T](cap)` | `func Ring[T any](capacity int) RingBuffer[T]` | Constructs an empty circular buffer with maximum capacity `cap`. |
| `r.Push(v)` | `func (r *RingBuffer[T]) Push(v T)` | Inserts `v` at the back. Overwrites oldest if at capacity. |
| `r.Pop()` | `func (r *RingBuffer[T]) Pop() adt.Option[T]` | Removes and returns oldest element, or `None` if empty. |
| `r.Peek()` | `func (r *RingBuffer[T]) Peek() adt.Option[T]` | Returns oldest element without removal, or `None` if empty. |
| `r.At(i)` | `func (r *RingBuffer[T]) At(i int) adt.Option[T]` | Returns element at logical offset `i` (`0` = oldest, `Len()-1` = newest). |
| `r.Len()` | `func (r *RingBuffer[T]) Len() int` | Returns current count of live elements. |
| `r.Cap()` | `func (r *RingBuffer[T]) Cap() int` | Returns buffer capacity. |
| `r.Full()` | `func (r *RingBuffer[T]) Full() bool` | Reports whether buffer is full. |
| `r.Empty()` | `func (r *RingBuffer[T]) Empty() bool` | Reports whether buffer is empty. |

### Zero-Copy Segmentation & Snapshotting

| Method | Signature | Description |
|---|---|---|
| `r.Segments()` | `func (r *RingBuffer[T]) Segments() (first, second []T)` | Returns zero-copy slice windows representing live elements in chronological order (`first[0]` is oldest). Designed to plug directly into `fn.FindRotated`. |
| `r.Linearize()` | `func (r *RingBuffer[T]) Linearize() []T` | Copies elements into a single contiguous slice in logical order. |
| `r.All()` | `func (r *RingBuffer[T]) All() iter.Seq[T]` | Returns an iterator yielding a snapshot of all elements from oldest to newest. |

```go
ring := ds.Ring[int](3)
ring.Push(1)
ring.Push(2)
ring.Push(3)
ring.Push(4) // Overwrites 1; contents are now [2, 3, 4]

first, second := ring.Segments()
// Directly binary search rotated partitions using fn:
idx := fn.FindRotated(first, second, 3, cmp.Compare)
```

## 2. SyncRingBuffer[T] (Thread-Safe Circular Buffer)

`SyncRingBuffer[T]` wraps `RingBuffer[T]` in an `async.Sync` mutex container. All operations are safe for concurrent access across goroutines.

### Construction & API

```go
ring := ds.GuardedRing[Event](1000)
```

| Method | Signature | Description |
|---|---|---|
| `GuardedRing[T](cap)` | `func GuardedRing[T any](capacity int) *SyncRingBuffer[T]` | Constructs a thread-safe circular buffer. |
| `s.Push(v)` | `func (s *SyncRingBuffer[T]) Push(v T)` | Thread-safe push under write lock. |
| `s.Pop()` | `func (s *SyncRingBuffer[T]) Pop() adt.Option[T]` | Thread-safe pop under write lock. |
| `s.Peek()` | `func (s *SyncRingBuffer[T]) Peek() adt.Option[T]` | Thread-safe peek under read lock. |
| `s.At(i)` | `func (s *SyncRingBuffer[T]) At(i int) adt.Option[T]` | Thread-safe random access under read lock. |
| `s.Len()` / `Cap()` | Return element count or capacity under read lock. |
| `s.Full()` / `Empty()` | Report full/empty state under read lock. |
| `s.Segments()` | `func (s *SyncRingBuffer[T]) Segments() (first, second []T)` | Returns cloned slice copies of partitions under read lock. |
| `s.Linearize()` | `func (s *SyncRingBuffer[T]) Linearize() []T` | Returns copy of linearized buffer under read lock. |
| `s.All()` | `func (s *SyncRingBuffer[T]) All() iter.Seq[T]` | Returns iterator over snapshot taken under read lock. |

## 3. Table[V] (Multi-Index In-Memory Relational Store)

`Table[V]` stores pointers to records `*V` indexed simultaneously by multiple fields. The first unique index serves as the Primary Key.

### Key Features
- **Two-phase atomic insertion**: Validates uniqueness constraints across all indexes before inserting; if any constraint fails, the insertion aborts with zero side effects.
- **Automatic index updates**: `Insert` and `Delete` update all declared indexes atomically.

### Index Declarations

| Function | Signature | Description |
|---|---|---|
| `UniqueIndex[V, K]` | `func UniqueIndex[V any, K comparable](extract func(*V) K) Unique[V, K]` | Declares a unique 1-to-1 index on `*V` extracting key `K`. |
| `NonUniqueIndex[V, K]`| `func NonUniqueIndex[V any, K comparable](extract func(*V) K) NonUnique[V, K]`| Declares a secondary 1-to-many index on `*V` extracting key `K`. |

### Table Operations

```go
type User struct {
    id    string
    email string
    role  string
}

func (u *User) ID() string    { return u.id }
func (u *User) Email() string { return u.email }
func (u *User) Role() string  { return u.role }

// Declare indices using method expressions:
var (
    ByID    = ds.UniqueIndex((*User).ID)
    ByEmail = ds.UniqueIndex((*User).Email)
    ByRole  = ds.NonUniqueIndex((*User).Role)
)

table := ds.NewTable(ByID, ByEmail, ByRole)
```

| Method / Function | Signature | Description |
|---|---|---|
| `NewTable[V, PK](pk, sec...)` | `func NewTable[V any, PK comparable](pk Unique[V, PK], secondary ...Index[V]) *Table[V]` | Creates table. First index is Primary Key. |
| `t.Insert(v)` | `func (t *Table[V]) Insert(v *V) bool` | Inserts record. Returns `false` if primary key or unique index constraint is violated. |
| `t.Delete(v)` | `func (t *Table[V]) Delete(v *V) bool` | Deletes record from table and all indexes. |
| `t.Len()` | `func (t *Table[V]) Len() int` | Returns count of records in main table. |
| `t.Clear()` | `func (t *Table[V]) Clear()` | Removes all records and clears all indexes. |

### Querying Views

Querying can be done via index methods or fluent free functions:

```go
// Direct query via index:
userOpt := ByID.Find(table, "u101")           // adt.Option[*User]
byEmailOpt := ByEmail.Find(table, "a@b.com")   // adt.Option[*User]
admins := ByRole.Find(table, "admin")          // []*User

// Functional query syntax:
userOpt = ds.By(table, ByID).Find("u101")
admins = ds.ByGroup(table, ByRole).Find("admin")
count := ds.ByGroup(table, ByRole).Count("admin")
```

## 4. Grid[R, C, V] (2D Sparse Coordinate Table)

`Grid[R, C, V]` stores sparse values `V` addressed by a 2D coordinate `(Row R, Col C)`. It automatically maintains bidirectional secondary index slices (`Row -> []Col` and `Col -> []Row`) for efficient zero-allocation slicing.

### Type Definition & Construction

```go
type Coord[R comparable, C comparable] struct {
    Row R
    Col C
}

grid := ds.NewGrid[string, string, int]()
```

### Cell Manipulation

| Method | Signature | Description |
|---|---|---|
| `g.Put(r, c, v)` | `func (g *Grid[R, C, V]) Put(r R, c C, v V) adt.Option[V]` | Sets value at `(r, c)`. Returns `Some(prevValue)` if updated, or `None` if new. |
| `g.Get(r, c)` | `func (g *Grid[R, C, V]) Get(r R, c C) adt.Option[V]` | Retrieves value at `(r, c)`, or `None` if absent. |
| `g.Remove(r, c)` | `func (g *Grid[R, C, V]) Remove(r R, c C) adt.Option[V]` | Deletes cell at `(r, c)` and prunes empty row/col indices. Returns `Some(oldVal)` if removed. |
| `g.Contains(r, c)` | `func (g *Grid[R, C, V]) Contains(r R, c C) bool` | Reports whether coordinate `(r, c)` exists. |
| `g.ContainsRow(r)` | `func (g *Grid[R, C, V]) ContainsRow(r R) bool` | Reports whether row `r` has any populated cells. |
| `g.ContainsCol(c)` | `func (g *Grid[R, C, V]) ContainsCol(c C) bool` | Reports whether column `c` has any populated cells. |
| `g.Len()` | `func (g *Grid[R, C, V]) Len() int` | Returns total number of populated cells. |
| `g.Clear()` | `func (g *Grid[R, C, V]) Clear()` | Clears all cells and secondary indexes. |

### Row & Column Iterators (Zero Allocations)

| Method | Signature | Description |
|---|---|---|
| `g.Row(r)` | `func (g *Grid[R, C, V]) Row(r R) iter.Seq2[C, V]` | Yields `(Col, Val)` pairs for row `r`. |
| `g.Col(c)` | `func (g *Grid[R, C, V]) Col(c C) iter.Seq2[R, V]` | Yields `(Row, Val)` pairs for column `c`. |
| `g.RowKeys()` | `func (g *Grid[R, C, V]) RowKeys() iter.Seq[R]` | Yields distinct populated row keys. |
| `g.ColKeys()` | `func (g *Grid[R, C, V]) ColKeys() iter.Seq[C]` | Yields distinct populated column keys. |
| `g.All()` | `func (g *Grid[R, C, V]) All() iter.Seq2[Coord[R, C], V]` | Yields `(Coord[R, C], V)` pairs for all populated cells. |
| `g.Values()` | `func (g *Grid[R, C, V]) Values() iter.Seq[V]` | Yields all cell values. |

```go
grid := ds.NewGrid[string, string, Permission]()
grid.Put("engineering", "repo:read", PermAllow)
grid.Put("engineering", "repo:write", PermAllow)
grid.Put("marketing", "repo:read", PermAllow)

// Iterate through all permissions assigned to "engineering"
for col, perm := range grid.Row("engineering") {
    fmt.Printf("Perm: %s -> %v\n", col, perm)
}
```

## 5. Practical Real-World Scenarios

### Scenario A: Moving Window Sensor Smoothing (`RingBuffer[T]`, `Segments`)

Maintaining a continuous moving average of the last $N$ sensor telemetry samples without heap allocations on each new sample:

```go
type MovingAverageFilter struct {
    ring ds.RingBuffer[float64]
}

func NewMovingAverage(windowSize int) *MovingAverageFilter {
    return &MovingAverageFilter{ring: ds.Ring[float64](windowSize)}
}

func (f *MovingAverageFilter) Add(sample float64) float64 {
    f.ring.Push(sample)

    // Zero-copy traversal across the two ring partitions:
    first, second := f.ring.Segments()
    
    total := stream.Of(first).Reduce(0.0, func(acc, v float64) float64 { return acc + v }) +
             stream.Of(second).Reduce(0.0, func(acc, v float64) float64 { return acc + v })

    return total / float64(f.ring.Len())
}
```

### Scenario B: Multi-Indexed Employee Directory with Collision Rollback (`Table[V]`)

An in-memory store indexing personnel records by primary key (Employee ID), unique SSN/Email, and secondary department groups:

```go
type Employee struct {
    id         string
    nationalID string
    department string
    salary     int
}

func (e *Employee) ID() string         { return e.id }
func (e *Employee) NationalID() string { return e.nationalID }
func (e *Employee) Department() string { return e.department }

var (
    ByEmpID      = ds.UniqueIndex((*Employee).ID)
    ByNationalID = ds.UniqueIndex((*Employee).NationalID)
    ByDept       = ds.NonUniqueIndex((*Employee).Department)
)

func ManageEmployeeRegistry() {
    registry := ds.NewTable(ByEmpID, ByNationalID, ByDept)

    emp1 := &Employee{id: "E101", nationalID: "SSN-9991", department: "Engineering", salary: 120000}
    emp2 := &Employee{id: "E102", nationalID: "SSN-9992", department: "Engineering", salary: 110000}
    empCollision := &Employee{id: "E103", nationalID: "SSN-9991", department: "Sales", salary: 90000}

    registry.Insert(emp1)
    registry.Insert(emp2)

    // Fails atomically: "SSN-9991" collides with emp1 on ByNationalID
    // Zero mutations occur on ByEmpID or ByDept
    success := registry.Insert(empCollision)
    fmt.Println("Collision insert succeeded:", success) // false

    // Query 1-to-1 by Primary Key
    foundOpt := ByEmpID.Find(registry, "E101") // adt.Option[*Employee]
    
    // Query 1-to-many by Secondary Group
    engineers := ByDept.Find(registry, "Engineering") // []*Employee (len = 2)
    engCount := ds.ByGroup(registry, ByDept).Count("Engineering") // 2

    // Clean deletion removes employee from all 3 indices
    registry.Delete(emp1)
    fmt.Println("Remaining engineers:", ds.ByGroup(registry, ByDept).Count("Engineering")) // 1
}
```

### Scenario C: Multi-Tenant RBAC Matrix & Sparse Route Table (`Grid[R, C, V]`)

Representing a 2D sparse matrix of permissions mapping `Role x Resource -> AccessLevel`, with fast queries along both axes:

```go
type AccessLevel int

const (
    AccessDeny AccessLevel = iota
    AccessRead
    AccessWrite
    AccessAdmin
)

func SetupRBACMatrix() *ds.Grid[string, string, AccessLevel] {
    matrix := ds.NewGrid[string, string, AccessLevel]()

    // Populate sparse permissions
    matrix.Put("admin", "billing", AccessAdmin)
    matrix.Put("admin", "users", AccessAdmin)
    matrix.Put("manager", "users", AccessRead)
    matrix.Put("developer", "source_code", AccessWrite)
    matrix.Put("contractor", "source_code", AccessRead)

    // Query 1: What can "admin" access? (Row Slicing)
    for resource, access := range matrix.Row("admin") {
        fmt.Printf("Admin on %s: %v\n", resource, access)
    }

    // Query 2: Who has any access to "source_code"? (Column Slicing)
    for role, access := range matrix.Col("source_code") {
        fmt.Printf("Role %s has %v on source_code\n", role, access)
    }

    // Dynamic revocation: prunes the coordinate and cleans index structures
    matrix.Remove("contractor", "source_code")
    fmt.Println("Contractor has access:", matrix.Contains("contractor", "source_code")) // false

    return matrix
}
```
