# Chapter 2: Pure Functional Utilities (`fn`)

The `fn` package provides pure, stateless utilities for everyday programming: value transforms, bound predicates, point-free function composition, circular sequence algorithms, string transforms, and format converters (JSON, Numeric, Time, Base64, URL).

```go
import "github.com/azuiktech/kleisli-go/fn"
```

---

## 1. Value Helpers

Stateless helpers for handling pointers, fallbacks, conditional values, error wrapping, and side effects without verbose `if/else` statements.

| Function | Signature | Description |
|---|---|---|
| `Must[T]` | `func Must[T any](val T, err error) T` | Returns `val` if `err == nil`; panics with `err` otherwise. |
| `WrapErr` | `func WrapErr(err error, format string, args ...any) error` | Returns `nil` if `err == nil`. Otherwise wraps `err` using `fmt.Errorf`. Appends `: %w` if omitted. |
| `MapErr[T]` | `func MapErr[T any](val T, err error, format string, args ...any) (T, error)` | Returns `(val, nil)` if `err == nil`; otherwise returns `(val, wrappedErr)`. |
| `Fallback[T]` | `func Fallback[T any](val T, err error, fallback T) T` | Returns `val` if `err == nil`; otherwise returns `fallback`. |
| `FallbackGet[T]` | `func FallbackGet[T any](val T, err error, fn func(error) T) T` | Returns `val` if `err == nil`; otherwise computes fallback via `fn(err)`. |
| `Cond[T]` | `func Cond[T any](condition bool, ifTrue T, ifFalse T) T` | Returns `ifTrue` if `condition` is true, else `ifFalse` (eager evaluation). |
| `CondGet[T]` | `func CondGet[T any](condition bool, ifTrue func() T, ifFalse func() T) T` | Lazy ternary evaluator: executes only the matching closure. |
| `Ptr[T]` | `func Ptr[T any](v T) *T` | Returns a pointer referencing a heap copy of `v`. |
| `Deref[T]` | `func Deref[T any](ptr *T, fallback T) T` | Returns `*ptr` if `ptr != nil`; otherwise returns `fallback`. |
| `DerefGet[T]` | `func DerefGet[T any](ptr *T, fn func() T) T` | Returns `*ptr` if `ptr != nil`; otherwise computes fallback via `fn()`. |
| `DerefZero[T]` | `func DerefZero[T any](ptr *T) T` | Returns `*ptr` if `ptr != nil`; otherwise returns the zero value of `T`. |
| `Tap[T]` | `func Tap[T any](val T, sideEffect func(T)) T` | Executes `sideEffect(val)` and returns `val` unchanged. |
| `Pipe[A, B]` | `func Pipe[A, B any](val A, f func(A) B) B` | Passes `val` through function `f`, returning `f(val)`. |
| `Zero[T]` | `func Zero[T any]() T` | Returns the zero value of type `T`. |
| `IsZero[T]` | `func IsZero[T comparable](v T) bool` | Reports whether `v` equals the zero value of `T`. |
| `Clamp[T]` | `func Clamp[T cmp.Ordered](v, lo, hi T) T` | Restricts `v` to the closed interval `[lo, hi]`. |
| `Coalesce[T]` | `func Coalesce[T comparable](vals ...T) T` | Returns the first non-zero element from `vals`, or zero if none. |

```go
port := fn.Deref(cfg.Port, 8080)
label := fn.Cond(isAdmin, "Admin", "User")
timeout := fn.Clamp(reqTimeout, 100*time.Millisecond, 5*time.Second)
activeHost := fn.Coalesce(overrideHost, envHost, "localhost")
```

## 3. Point-Free Function Composition (Tacit Programming)

Provides left-to-right composition and array-language forks over typed function primitives.

### Types & Combinators

```go
type Fn[T, U any] func(T) U
type Fn2[A, B, U any] func(A, B) U
```

| Method / Function | Signature | Description |
|---|---|---|
| `f.Then(g)` | `func (f Fn[T, U]) Then[V any](g Fn[U, V]) Fn[T, V]` | Composes functions left-to-right: `g(f(x))`. |
| `combine.Fork(f, g)` | `func (combine Fn2[A, B, U]) Fork[T any](f Fn[T, A], g Fn[T, B]) Fn[T, U]` | Forks input `x` to `f(x)` and `g(x)`, passing results to `combine(f(x), g(x))`. |
| `Identity[T]` | `func Identity[T any](x T) T` | Returns `x` unchanged. |
| `Constant[T, U]` | `func Constant[T, U any](val U) func(T) U` | Returns a function that ignores input and always yields `val`. |

```go
// Fork example: computing Mean = Sum(x) / Count(x)
sum := func(xs []float64) float64 { /* sum */ }
count := func(xs []float64) float64 { return float64(len(xs)) }
div := func(s, c float64) float64 { return s / c }

mean := fn.Fn2[float64, float64, float64](div).Fork(sum, count)
avg := mean([]float64{10, 20, 30}) // 20.0
```

## 4. Rotated Sequence Algorithms

Optimized binary search algorithms over circular, rotated, or partition-wrapped sequences. Directly integrates with `ds.RingBuffer.Segments()`.

| Function | Signature | Description |
|---|---|---|
| `FindRotated[T, V]` | `func FindRotated[T, V any](first, second []T, val V, comp func(T, V) int) int` | Binary-searches two partitions of a rotated sequence. Returns logical index `n \in [0, len(first)+len(second)]`. |
| `After[T]` | `func After[T any](first, second []T, n int) ([]T, []T)` | Returns zero-copy circular views of elements occurring strictly after index `n`. |
| `Before[T]` | `func Before[T any](first, second []T, n int) ([]T, []T)` | Returns zero-copy circular views of elements occurring strictly before index `n`. |
| `FindRotatedWithPivot[T, V]` | `func FindRotatedWithPivot[T, V any](s []T, pivot int, val V, comp func(T, V) int) int` | Searches `s[pivot:]` then `s[:pivot]`, returning physical slice index into `s`. |
| `AfterWithPivot[T]` | `func AfterWithPivot[T any](s []T, pos, pivot int) ([]T, []T)` | Circular slice views after physical position `pos`. |
| `BeforeWithPivot[T]` | `func BeforeWithPivot[T any](s []T, pos, pivot int) ([]T, []T)` | Circular slice views before physical position `pos`. |

```go
// Using FindRotated with a circular buffer
first, second := ring.Segments()
idx := fn.FindRotated(first, second, targetID, cmpFunc)
if idx < len(first)+len(second) {
    afterFirst, afterSecond := fn.After(first, second, idx)
    // process items chronologically newer than targetID
}
```

## 7. Practical Real-World Scenarios

### Scenario A: Point-Free Statistical Pipeline (`Fn`, `Fn2`, `Fork`, `Then`)

Composing a purely declarative Standard Deviation pipeline:
$\sigma = \sqrt{\frac{1}{N}\sum_{i=1}^N (x_i - \mu)^2}$

```go
func sum(xs []float64) float64 {
    return stream.Of(xs).Reduce(0.0, func(acc, v float64) float64 { return acc + v })
}

func count(xs []float64) float64 { return float64(len(xs)) }
func divide(s, c float64) float64 { return s / c }
func mean(xs []float64) float64  { return divide(sum(xs), count(xs)) }
func subtract(a, b float64) float64 { return a - b }
func square(x float64) float64   { return x * x }

// Point-free composition using Fork and Then
var StdDev = func(data []float64) float64 {
    mu := mean(data)
    variance := stream.Of(data).
        Map(func(x float64) float64 { return square(subtract(x, mu)) }).
        Reduce(0.0, func(acc, v float64) float64 { return acc + v }) / count(data)
    return math.Sqrt(variance)
}
```

### Scenario B: Telemetry Window Lookup Over Rotated Ring Segments (`FindRotated`, `After`)

Querying time-series events strictly newer than a specific timestamp from a circular ring buffer without allocating a linearized copy:

```go
type MetricPoint struct {
    Timestamp int64
    Value     float64
}

func (m MetricPoint) TimestampVal() int64 { return m.Timestamp }

func compareTimestamp(pt MetricPoint, target int64) int {
    return cmp.Compare(pt.Timestamp, target)
}

func GetMetricsSince(ring *ds.RingBuffer[MetricPoint], sinceTimestamp int64) []MetricPoint {
    first, second := ring.Segments()
    idx := fn.FindRotated(first, second, sinceTimestamp, compareTimestamp)

    // Not found or target is beyond the latest point
    if idx >= len(first)+len(second) {
        return nil
    }

    // Zero-copy view of items strictly after index
    newerFirst, newerSecond := fn.After(first, second, idx)
    return slices.Concat(newerFirst, newerSecond)
}
```

### Scenario C: Multi-Factor Financial Transaction Validator (`AllOf`, `AnyOf`, `In`)

Composable rules evaluating payment limits, velocity, and country blacklists:

```go
type Transaction struct {
    AmountUSD float64
    Country   string
    IsVIP     bool
    RiskScore int
}

func (t Transaction) Amount() float64 { return t.AmountUSD }
func (t Transaction) Risk() int       { return t.RiskScore }

var (
    blockedCountries = []string{"XX", "YY", "ZZ"}
    
    amountWithinLimit = func(t Transaction) bool { return t.AmountUSD <= 10_000.0 }
    validCountry      = func(t Transaction) bool { return fn.NotIn(blockedCountries...)(t.Country) }
    lowRiskScore      = func(t Transaction) bool { return t.RiskScore < 75 }
    isVipCustomer     = func(t Transaction) bool { return t.IsVIP }

    // Business Rule: Valid if not blocked AND (VIP OR (Amount within limit AND Low Risk))
    ApproveTransaction = fn.And(
        validCountry,
        fn.Or(
            isVipCustomer,
            fn.And(amountWithinLimit, lowRiskScore),
        ),
    )
)
```
